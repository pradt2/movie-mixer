# TASK_05 — Composition rendering and export

Prerequisite: TASK_04. Read AGENTS.md. Render what the project actually describes; do not use the source viewer as a substitute for output.

## Implement
- Construct a pure render plan from an immutable project snapshot and a requested half-open output interval. Partition at clip boundaries, resolve video stacking, retain all enabled audio contributions, and represent gaps explicitly. Define exact-to-output-frame/sample quantisation once, with documented rounding and cumulative error bounds. Use global output indices rather than independently rounding durations of successive clips.
- Implement FFmpeg execution for the plan. Decode selected streams by actual stream index, map asset-local timestamps correctly, trim and retime, normalise video geometry (preserve aspect ratio with padding), frame rate and pixel format, and concatenate/composite resolved picture. Honour clip rate; silence/black fill absent media. Mix audio contributions with per-clip gain, fades, sample rate/channel-layout conversion and pitch-preserving tempo correction (chain atempo stages if necessary). Fades apply in output time and must match the domain envelope. Use a defined clipping policy, warn about potential overload and avoid silently normalising each clip independently.
- Handle VFR and nonzero stream offsets explicitly. Define timestamp handling for discontinuities and source decode preroll. If an encountered media feature cannot be rendered correctly, fail with a useful message. Do not silently select an alternative stream, crop, shift timing or drop audio.
- Support a practical initial export preset: MP4 with H.264/AAC (check encoder availability) and explicit resolution, frame rate, sample rate and channel layout; allow video-only/audio-only composition through black/silence where appropriate. Do not claim bit-exact passthrough, HDR preservation, arbitrary channel-layout support or lossless export. Reject unsupported formats clearly; document colour handling and constraints.
- Expose export settings, destination, progress, cancel and useful error diagnostics. Write to a temporary sibling file then rename on success, protecting existing outputs unless the user explicitly confirms replacement. Never overwrite an input. Clean up cancelled/failed renders. Keep the GUI responsive and snapshot edits independently of a running export.
- Bound the number of simultaneous decoders/processes and temporary storage use. Long or complex compositions may render in chunks, but chunk joins must preserve timing and not reset fades or mix semantics.

## Acceptance
- Generate a fixture composition with distinguishable colours and tones, overlapping video tracks, mixed audio, gaps, a fractional rate and independently selected streams. Decode exported frames and audio and compare expected colours, timing, spectral components, gaps and fade levels with tolerances justified by encoding.
- Test stream offsets, VFR or irregular PTS, a non-frame-aligned boundary, render ranges and long-duration planning without needing a full-length film. Confirm output duration within one frame / documented audio encoder padding. Test failure and cancellation, non-overwrite protection, and stable snapshots.
- Manually export a short mixed composition and play the result in an independent player. Record unsupported cases and unexecuted tests. No preview-specific alternate composition rules.
